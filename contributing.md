# Contribution

## Messages de commit

Les commits suivent la convention Conventional Commits.

### Types disponibles

- `feat` : ajout d'une fonctionnalité
- `fix` : correction d'un bug
- `docs` : modification de la documentation
- `style` : modification du formatage du code
- `refactor` : amélioration de la structure du code
- `test` : ajout ou modification de tests
- `chore` : maintenance générale du projet
- `perf` : amélioration des performances
- `ci` : modification de l'intégration continue
- `build` : modification du système de build ou des dépendances
- `revert` : annulation d'un commit précédent

## Format

### Les messages doivent respecter le format suivant :

**type: description courte**
