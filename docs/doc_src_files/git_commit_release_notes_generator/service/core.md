# Core du service

Fichier source associé : src/git_commit_release_notes_generator/service/core.py

## Description

Ce module est le noyau de la logique applicative. Il est destiné à regrouper les principales fonctions métier de génération et d’orchestration.

## Rôle fonctionnel

- recevoir les données de diff ;
- orchestrer les appels à la couche LLM ;
- préparer les structures de sortie ;
- centraliser les traitements de validation métier.

## Points d’attention

Comme le fichier est vide actuellement, il est un bon emplacement pour les fonctions d’orchestration qui seront ajoutées au fil des sprints.
