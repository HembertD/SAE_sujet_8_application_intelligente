# Utilitaires de service

Fichier source associé : src/git_commit_release_notes_generator/service/utils.py

## Description

Ce module réunit les fonctions utilitaires destinées à simplifier le traitement, la validation et le filtrage des données transitant entre le diff Git et la génération de message.

## Rôle attendu

- mettre en forme les données ;
- normaliser les entrées ;
- factoriser les blocs de logique réutilisables ;
- isoler les opérations auxiliaires du cœur métier.
