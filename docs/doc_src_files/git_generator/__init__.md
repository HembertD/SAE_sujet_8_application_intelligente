# Module git_generator

Fichier source associé : src/git_generator/__init__.py

## Rôle

Ce package centralise les fonctionnalités liées à Git et à l’extraction d’informations depuis les dépôts.

## Sous-modules

- [service](service/__init__.md) : wrapper et utilitaires autour de Git.

## Objectif

Le module est pensé pour préparer les données Git au bon format avant qu’elles ne soient consommées par la génération de messages ou de release notes.
