# SAE - Application intelligente

Documentation du projet d'application intelligente.

Cette documentation présente l'architecture technique, les tests, le suivi de projet et les mécanismes de CI/CD associés.

## Documentation technique

La documentation technique suit la structure du code source et des tests.

- `doc_src_files` : documentation des fichiers du dossier `src`
- `doc_test_files` : documentation des fichiers du dossier `test`
- `monitoring` : suivi des sprints et de l'avancement du projet

## CI et déploiement

Le projet met en place deux éléments essentiels de documentation opérationnelle :

- le [déploiement de la documentation](deploiement_documentation.md) : explication du build MkDocs et de la publication sur GitHub Pages
- les [tests automatiques via GitHub Actions](deploiement_tests_workflows.md) : explication du lancement des tests et de leur organisation dans la CI
