# Calculatrice Python

Une calculatrice simple en ligne de commande écrite en Python.

## Fonctionnalités
- Addition (`add`)
- Soustraction (`sub`)
- Multiplication (`mul`)
- Division (`div`)

## Utilisation

```bash
python calculator.py add 10 5
# Résultat: 15.0

python calculator.py mul 6 7
# Résultat: 42.0
```

## Lancer les tests

```bash
python -m unittest discover tests
```
